# Кейс 4 - «Деловые заметки»

Проект реализован на Java в Android Studio. 
Приложение предназначено для фиксации встреч, задач и договоренностей с датой и временем.

## Функциональные возможности

- создание, просмотр, редактирование и удаление заметок;
- каждая заметка содержит: заголовок, содержание, дату и время события;
- поиск по заголовку, содержанию, дате и типу хранилища;
- два способа локального хранения на выбор:
  - база данных SQLite;
  - отдельные JSON-файлы во внутреннем каталоге приложения;
- изменение способа хранения при редактировании заметки;
- сортировка по времени последнего изменения;
- удаление с подтверждением.

Приложение работает без сети и не запрашивает разрешения на доступ к общему хранилищу.
Данные SQLite и JSON находятся во внутренней области приложения, поэтому недоступны другим приложениям без специальных средств разработчика.

## Использованные технологии

- Java 17;
- Android SDK: `compileSdk 35`, `targetSdk 35`, `minSdk 24`;
- AndroidX AppCompat и RecyclerView;
- Material Components;
- `SQLiteOpenHelper` для базы данных;
- `JSONObject` и внутреннее файловое хранилище Android для JSON-файлов;
- Gradle 8.10.2 и Android Gradle Plugin 8.7.3.

## Структура проекта

```text
app/src/main/java/com/example/meetingnotes/
├── MainActivity.java          главный экран и поиск
├── NoteEditActivity.java      форма создания и редактирования
├── NoteAdapter.java           карточки RecyclerView
├── Note.java                  модель заметки
├── NoteRepository.java        единый доступ к двум хранилищам
├── DatabaseHelper.java        CRUD в SQLite
├── FileStorageHelper.java     чтение и запись JSON-файлов
└── DateFormatter.java         формат даты и времени
```

## Запуск в Android Studio

1. Распакуйте архив в каталог без кириллицы в пути, например `C:\AndroidProjects\MeetingNotes`.
2. Запустите Android Studio и выберите **File → Open**.
3. Дождитесь завершения **Gradle Sync**. При первом запуске потребуется Интернет для загрузки Gradle и зависимостей.
4. Если Android Studio предложит установить Android SDK 35, согласитесь либо установите его через **Tools → SDK Manager**.
5. Создайте эмулятор в **Tools → Device Manager** или подключите телефон с включенной USB-отладкой.
6. Выберите конфигурацию `app` и нажмите **Run**.

Требования: Android Studio с поддержкой JDK 17, Android SDK 35 и устройство/эмулятор с Android 7.0 (API 24) или новее.

## Шаги отладки

1. Создайте заметку с хранением в SQLite.
2. Создайте вторую заметку с хранением в JSON-файле.
3. Найдите обе записи по фрагменту заголовка и по дате.
4. Измените текст, дату и способ хранения одной записи.
5. Закройте и снова откройте приложение - данные должны сохраниться.
6. Удалите заметку и подтвердите удаление.
